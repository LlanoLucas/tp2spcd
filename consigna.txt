01  Objetivo

En este segundo entregable del caso de estudio sobre análisis de datos de vinos, nos adentraremos en el uso de herramientas y técnicas específicas de análisis de datos utilizando R y Python, así como la introducción a la programación en Python y R para ciencia de datos.
Este módulo se centra en capacitar a los participantes en el uso de R y Python para realizar análisis exploratorio de datos, procesamiento de datos y programación aplicada a la ciencia de datos. A través de ejercicios prácticos y aplicados al conjunto de datos de reseñas de vinos, exploraremos cómo estas herramientas pueden ser utilizadas para comprender mejor las características, tendencias y preferencias de los vinos.
El análisis de datos con R y Python nos permitirá explorar la estructura de los datos, realizar estadísticas descriptivas, crear visualizaciones informativas y preparar los datos para análisis más avanzados. Además, la introducción a la programación en Python y R nos ayudará a desarrollar habilidades para manipular datos, resolver problemas y aplicar modelos analíticos que puedan revelar información valiosa para la industria del vino.
Este trabajo práctico no solo busca fortalecer nuestras habilidades técnicas en análisis de datos y programación, sino también prepararnos para enfrentar nuevos desafíos en la extracción e interpretación de información relevante a partir de grandes volúmenes de datos.

03  Consigna abierta

Realizar un análisis exploratorio detallado del conjunto de datos de reseñas de vinos utilizando tanto R como Python. Este análisis nos permitirá comprender la estructura de los datos, identificar problemas potenciales y preparar los datos para análisis más avanzados.

Carga del archivo:
    • Utilizar R y Python para cargar el archivo winemag-data-130k-v2.csv.
    • Revisar el formato del archivo, asegurándose de que se haya cargado correctamente.
    • Verificar la cantidad de datos, número de columnas y tipos de datos presentes en el conjunto de datos.

Análisis exploratorio de datos:
    • Explorar la estructura general de los datos. ¿Qué variables están presentes? ¿Cuáles son las características principales del conjunto de datos?
    • Realizar un resumen estadístico inicial de las variables numéricas y categóricas importantes.
    • Explorar la distribución de las variables numéricas y categóricas mediante gráficos apropiados.

Tratamiento de datos faltantes:
    • Identificar y manejar los datos faltantes en el conjunto de datos. Justificando la elección
    • Discutir y describir diferentes estrategias para manejar los datos faltantes.

Análisis de datos atípicos:
    • Detectar posibles valores atípicos en las variables numéricas relevantes.
    • Evaluar la naturaleza y posible causa de estos valores atípicos.
    • Analizar cómo los valores atípicos pueden afectar el análisis y las decisiones basadas en los datos.

04  Formato entregable

En este trabajo práctico deberá hacer entrega de 2 (dos) archivos. Por un lado, un informe detallando el análisis de lo realizado y, por otro lado, el código utilizado para la realización del análisis. 

Script
Formato del archivo:
    • Prepara un archivo de script en R (.R) o Python (.py) según tu elección y habilidades. Por ejemplo, analisis_exploratorio_vinos.R o analisis_exploratorio_vinos.py.
Organización del código:
    • El código debe estar bien organizado en secciones lógicas que reflejen los pasos del análisis exploratorio: carga de datos, resumen estadístico, gráficos, tratamiento de datos faltantes, análisis de datos atípicos, respuestas a consignas específicas, etc.


Comentarios y documentación:

    • Incluye comentarios adecuados a lo largo del código para explicar cada paso, especialmente para funciones complejas o decisiones analíticas importantes.
    • Asegúrate de que los nombres de las variables y funciones sean descriptivos y claros.
Funcionalidad completa:
    • El script debe ser completamente funcional y capaz de ejecutarse sin errores si se proporciona el archivo de datos winemag-data-130k-v2.csv.
